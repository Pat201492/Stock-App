Update the data

This site serves a read-only snapshot, so the data refresh runs on your own machine and then publishes the result here. Run the one-liner below — it installs the app if you don't have it, refreshes the data, and pushes it live.

macOS / Linux

Publishing requires SSH access to the server (configured once via publish.config.ps1 on Windows or STOCKAPP_VPS_HOST on macOS/Linux). Machines without that just build the data locally — they can't push. See deploy/README.md for setup.
