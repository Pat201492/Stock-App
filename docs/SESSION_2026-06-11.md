## Part 2 — Congress-data freshness fix (the real problem)

**Symptom:** the new Politicians views showed nothing past **Jan 29, 2026**.

**Diagnosis:** not our bug. `ingest_congress.py` pulls a third-party CSV
(`Peez49/Informed-Trading`, a Quiver rebundle) that **froze at 2026-01-30**. The legacy
Senate fallback (`senate-stock-watcher-data`) has been **dead since 2020-12**. The
nightly `pol_refresh.py` (run by `publish.ps1` at 03:00 — already scheduled) kept
re-pulling the same frozen CSV. STOCK Act disclosure window is **45 days**, so a live
feed should reach ~late April by June; both mirrors were stale.

**Fix:** ingest directly from the **official primary sources**, which are current.

### House — PR #65 (`ingest_house.py`)
- Index: `disclosures-clerk.house.gov/public_disc/financial-pdfs/{year}FD.zip`
  (`{year}FD.txt`, tab-delimited; `FilingType == 'P'` = Periodic Transaction Report).
- Per-filing PTR PDFs: `/public_disc/ptr-pdfs/{year}/{DocID}.pdf`.
- Text via **pypdf** (added to `requirements.txt`) — chosen over `pdftotext` because
  the two emit the table in different orders; pypdf puts the `(TICKER)` line before the
  data line, which the parser targets.
- Parser handles: wrapped `(TICKER)`/`[ST]`, concatenated dates `MM/DD/YYYYMM/DD/YYYY`,
  `S (partial)/(full)` → sale_partial/sale_full, owner codes SP/JT/DC; **skips**
  bonds/funds (CUSIPs start with a digit → no alpha ticker) and scanned PDFs.
- Name→bioguide via the committees-seeded `Politician` table + **State/District**
  disambiguation (`GA12`).
- First run: **inserted 7,681**, scanned 76, unmatched 75, **latest 2026-06-11**.

### Senate — PR #66 (`ingest_senate_efd.py`)
- `efdsearch.senate.gov`: GET home → scrape CSRF → POST accept-terms (session cookie)
  → paginated `POST /search/report/data/` (report_types = PTR).
- E-filed reports are **clean HTML tables** (lxml) — far simpler than House PDFs; paper
  PDFs skipped + logged.
- Name→bioguide with a **unique-active-last-name fallback** for nickname mismatches
  (Jim/James, Mike/Michael, Dave/David).
- Full backfill: **8,941 Senate trades, latest 2026-06-05**.

### Wiring / retiring
- `pol_refresh.py` default `ALL` is now **committees → house → senate_efd →
  insider_mirror**. `--congress` (peez49) and `--senate` (dead mirror) demoted to
  explicit-only/deprecated; historical rows kept (the API queries
  `congressional_trades` source-agnostically). Trade-id dedup means overlapping Senate
  rows previously attributed to peez49 are re-sourced to `senate_efd`.
